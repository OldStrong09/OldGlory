# TradePilot — Trading Demo Assistant

Aplicación web independiente para practicar trading en cuenta demo, controlar riesgo y analizar el propio historial.

## Incluye
- Dashboard de capital y curva de equity.
- Calculadora de riesgo y R:R.
- Mercado con gráfico integrado y selección de activo/timeframe.
- Plan de setup guardado localmente.
- Diario de operaciones.
- Estadísticas básicas y Profit Factor.
- Checklist de disciplina antes de entrar.
- Eliminación y persistencia local de operaciones.

## Importante
TradePilot no ejecuta operaciones, no conecta con un broker y no debe considerarse asesoramiento financiero. Está pensado para formación, simulación y registro.

## Privacidad
Los trades y el plan se guardan en el almacenamiento local del navegador. No se envían a un servidor por esta versión.
