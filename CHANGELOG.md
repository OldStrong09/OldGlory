# Changelog — Apex Ledger

## 2026-09-02

### Mejoras
- Validación automática de JavaScript en GitHub Actions antes de publicar.
- PWA mejorada con `scope`, orientación flexible y categorías.
- Service Worker actualizado para forzar la entrada de la nueva versión en caché.
- Backup JSON endurecido con validación de estructura antes de importar.
- Analítica avanzada protegida frente a datos locales corruptos o no numéricos.

### Seguridad y alcance
- La aplicación continúa siendo exclusivamente demo/manual.
- No existe conexión con brokers ni ejecución automática de órdenes.
- Los datos permanecen en el almacenamiento local del navegador en esta versión.

## Próximas mejoras técnicas
- Validación adicional de datos del diario antes de renderizar tablas.
- Flujo directo de plan de mercado → diario de trading.
- Métricas por sesión y horario.
- Mejoras de navegación móvil y visualización de la curva de equity.
